2. 그리드 기본 수치 정의 — root.css
============================================================

--auto: auto;
--GW-XXS: 320px;
--GW-XS: 768px;
--GW-S: 900px;
--GW-M: 1100px;
--GW-L: 1620px;

[설명]
- GW는 Grid Width의 의미로 사용한 이름이다.
- 화면 또는 콘텐츠 영역의 크기를 단계별로 저장한다.
- CSS 변수로 관리하면 같은 값을 여러 선택자에서 재사용할 수 있다.
- --auto는 auto를 변수로 저장한 것이지만, auto는 직접 작성해도 충분하다.

[주의]
- 현재 실제 코드의 --GW-S 값은 900px이다.
- 주석에는 1080 그리드라고 적혀 있으므로 변수명·값·주석을 혼동하지 않아야 한다.

3. 최소 너비용 변수 — root.css
============================================================

--GWM-S: 320px;
--GWM-M: ;

[설명]
- GWM은 최소 그리드 너비를 관리하려는 목적으로 만든 변수다.
- 단, --GWM-M에는 값이 없으므로 현재 유효한 CSS 값이 아니다.

4. 패딩 변수 — root.css
============================================================

--padding-grid-medium: var(--num80);
--padding-grid-largre: var(--num140);

[값의 연결 흐름]
--num80
  → 80px
  → --padding-grid-medium
  → 중간 크기의 좌우 패딩

--num140
  → 140px
  → --padding-grid-largre
  → 큰 크기의 좌우 패딩

[설명]
- 좌우 패딩 값이 같다면 왼쪽·오른쪽 변수를 각각 만들 필요가 없다.
- 하나의 패딩 변수를 양쪽에 함께 사용할 수 있다.
- largre는 오타이며 의미상 large가 맞다. 이 문서는 오늘 작성된 코드명을
  그대로 기록하기 위해 largre로 표기했다.

5. 용도별 그리드 변수와 중앙 정렬 — root.css
============================================================

--G-center: var(--num0) var(--auto);
--grid-1080: var(--GW-S);
--gridM-1080: var(--GWM-M);

[값의 연결 흐름]
--num0 = 0
--auto = auto
--G-center = 0 auto

따라서 다음 코드는 위아래 margin은 0으로 만들고,
남는 좌우 공간은 자동으로 나누어 요소를 가운데 정렬한다.

margin: var(--G-center);

[주의]
- --grid-1080이라는 이름과 달리 현재 연결된 --GW-S의 실제 값은 900px이다.
- --gridM-1080은 값이 비어 있는 --GWM-M을 참조하므로 유효하지 않다.

10. 1240px 반응형 메뉴 전환 — media.css
============================================================

.user-box-1240 {
  display: none;
}

@media screen and (max-width: 1240px) {
  .user-box {
    display: none;
  }

  .user-box-1240 {
    display: block;
  }
}

[동작]
- 화면이 1240px보다 클 때:
  · .user-box가 보인다.
  · .user-box-1240은 숨겨진다.

- 화면이 1240px 이하일 때:
  · 기존 .user-box를 숨긴다.
  · 대체 요소 .user-box-1240을 표시한다.

[핵심]
- 미디어쿼리는 디자인이 변화하는 시점인 브레이크포인트를 지정한다.
- max-width: 1240px은 화면 너비가 0~1240px일 때 적용된다는 뜻이다.

11. 1080px 반응형 그리드 — media.css
============================================================

@media screen and (max-width: 1080px) {
  header {
    min-width: var(--gridM-1080);
  }

  header .con {
    max-width: var(--GW-S);
    padding-left: var(--padding-grid-medium);
    padding-right: var(--padding-grid-medium);
    background-color: antiquewhite;
  }
}

[동작 의도]
- 화면이 1080px 이하가 되면 반응형 스타일을 적용한다.
- header .con의 최대 너비를 그리드 변수로 제한한다.
- 기본 좌우 패딩 140px을 중간 패딩 80px로 변경한다.
- antiquewhite 배경색은 적용 영역을 확인하기 위한 테스트 용도로 보인다.

[중요: 미디어쿼리와 CSS 변수]
다음과 같이 미디어쿼리 조건에 일반 CSS 변수를 넣을 수 없다.

@media screen and (max-width: var(--grid-1080)) { ... }

따라서 브레이크포인트는 다음처럼 직접 작성한다.

@media screen and (max-width: 1080px) { ... }

반면 미디어쿼리 내부의 일반 CSS 선언에서는 변수를 사용할 수 있다.

max-width: var(--GW-S);
padding-left: var(--padding-grid-medium);
padding-right: var(--padding-grid-medium);

[주의]
- 현재 --gridM-1080이 참조하는 --GWM-M의 값이 비어 있기 때문에
  min-width: var(--gridM-1080)은 정상 적용되지 않는다.
- 미디어쿼리 기준은 1080px이지만 --GW-S의 실제 값은 900px이다.
  즉, 1080px 이하에서 콘텐츠 최대 너비를 900px로 제한하는 구조다.

12. 오늘 학습한 핵심 요약
============================================================

1) CSS 변수는 값을 재사용하고 역할별 이름을 붙이는 데 사용한다.

2) 그리드 최대 너비와 그리드 패딩은 서로 다른 개념이다.
   - max-width: 콘텐츠가 커질 수 있는 최대 크기
   - padding: 콘텐츠와 컨테이너 경계 사이의 내부 여백

3) margin: 0 auto는 너비가 제한된 블록 요소를 가로 중앙에 배치한다.

4) 미디어쿼리의 max-width는 반응형 변화가 시작되는 기준점이다.

5) 미디어쿼리 조건에는 일반 CSS 변수 var()를 사용할 수 없다.
   브레이크포인트는 1080px처럼 직접 입력해야 한다.

6) 미디어쿼리 내부의 일반 속성값에는 CSS 변수를 사용할 수 있다.

7) header와 내부 .con의 역할을 나누면 다음처럼 관리할 수 있다.
   - header: 화면 전체 영역과 테두리
   - .con: 콘텐츠 너비, 중앙 정렬, 패딩, flex 배치

8) display: none/block을 미디어쿼리에서 전환하면 화면 크기에 따라
   데스크톱 메뉴와 축소 메뉴를 바꿀 수 있다.
